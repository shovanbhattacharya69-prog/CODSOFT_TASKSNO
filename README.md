# 🚀 CODSOFT Python Programming Internship Tasks

Welcome to the **CODSOFT_TASKSNO** repository! This repository contains a collection of professional, GUI-based desktop applications developed as part of the Python Programming Internship at CodSoft. 

Each project demonstrates a strong understanding of Python fundamentals, object-oriented programming (OOP), graphical user interface (GUI) design using `tkinter`, and robust error handling.

---

## 📂 Projects Overview

### Task 1: To-Do List Application
A highly functional, GUI-based task management application.
* **Features:** Add new tasks, mark tasks as complete (visual update), delete tasks, and scroll through task history.
* **Tech Focus:** State management, `tkinter` Listbox, scrollbar integration, and user input validation.

### Task 2: Standard Calculator
A responsive desktop calculator built with a scalable grid layout.
* **Features:** Basic arithmetic operations (addition, subtraction, multiplication, division), decimal support, clear function, and safe expression evaluation.
* **Tech Focus:** Grid geometry management, lambda functions for event binding, and graceful exception handling (e.g., catching `ZeroDivisionError`).

### Task 3: Rock-Paper-Scissors Game
An interactive player vs. computer game with dynamic logic and score tracking.
* **Features:** Randomized computer choices, win/loss/tie determination, persistent score tracking across rounds, and a reset mechanism.
* **Tech Focus:** `random` module integration, dynamic label updating, and game state persistence.

---

## 🛠️ Technology Stack

* **Language:** Python 3.x
* **GUI Framework:** `tkinter` (Python's standard GUI library)
* **Libraries Used:** `random`, `messagebox` (from `tkinter`)
